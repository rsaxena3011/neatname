# Neatname

Batch rename files in a folder. Preview every change before applying. Undo anytime.

One HTML file. No install, no account, works offline. Your files never leave your computer.

## Use it

Open `neatname.html` in Chrome or Edge on desktop. Click to pick a folder, set your rename rules, preview, then rename.

Or try it online: https://rsaxena3011.github.io/neatname/

## What it does

- **New name + numbering:** `File_001.jpg`, `File_002.jpg`, and so on
- **Find and replace:** swap text across all filenames at once
- **Prefix / suffix:** add text to the start or end
- **Case changes:** lowercase, UPPERCASE, Title Case
- **Clean spaces:** turns messy spaces into clean underscores
- **Conflict detection:** warns you before two files get the same name
- **Undo:** one click reverses the last batch

File extensions are always preserved.

## Requirements

Chrome or Edge on desktop (uses the File System Access API). Not supported on mobile or Firefox.
